# hxyfront-62009 地毯修复纹样档案

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 染料批次管理

针对「同一色号不同染料批次存在色差、返工找不回原批次」的问题：

- **色卡—批次**：每个颜色（色号）下维护多个染料批次，分别记录到货日期、到货量与当前余量；可随时登记新到货批次。
- **选批补线**：破损区域补线时必须选定具体批次，系统扣减该批余量、保留每笔用量并更新区域施工进度。
- **褪色停用**：某批次因褪色停用后，仅该批被冻结；其它批次、其他颜色与其他档案照常施工。所有正在使用该批的破损区域（跨档案）自动转为「待复核」，**原用量原样保留**。
- **复核换批**：待复核区域只能改用同色号的其他在用批次；换批后新批余量、区域进度、按产地筛选的列表一并更新，旧批用量保留可查，并生成一条 `旧批 → 新批` 的换批记录。
- **持久化**：档案通过浏览器 localStorage 全量落盘，关闭页面再回来仍能看到每一次登记、补线、停用与换批记录。

## 代码分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 批次规则 | `src/batchRules.ts` | 纯函数业务规则：选批、扣余量、停用波及、复核换批、进度计算；不依赖 React 与存储 |
| 档案存取 | `src/archiveStore.ts` / `src/seedData.ts` | localStorage 读写、版本校验与初始示例档案 |
| 页面状态 | `src/useStudioStore.ts` | React hook：取快照、调规则、落盘、操作反馈 |
| 页面组件 | `src/App.tsx`、`src/components/*` | 色卡面板、档案与破损区、换批日志的渲染与交互 |

纯规则逻辑附带冒烟测试：`npx vite-node scripts/smoke.mts`
