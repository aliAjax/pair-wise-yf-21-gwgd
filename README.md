# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案前端项目：记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序，并为色卡补上**染料批次台账**——同一色号按批次记录到货日期与余量，破损区域补线时选定具体批次，返工时能找回当时用过的那批线。

## 批次规则

- **入库**：每个色号（色卡）下可登记多个批次，记批次号、到货日期、到货量；余量初始等于到货量。
- **补线**：破损区域登记补线时必须选定该色号下的某个**可用批次**，用量从该批次余量中扣减；余量不足、色号不符、批次已停用都会被规则拒绝。区域状态随累计用量推进：待补线 → 修复中 → 已完工。
- **停用**：批次因褪色等原因停用后，只有用过该批的破损区域转为「待复核」并**保留原用量**；其它批次、其它档案照常施工，停用批次不再能取线。
- **复核换批**：待复核区域选定同色号的新批次继续，补用量从新批次扣减，原用量记录保留；色卡余量、区域进度、按产地筛选的档案列表从同一份状态派生，一起更新。
- **留痕**：入库、补线、停用、复核换批都会写入换批记录，刷新或关掉页面再回来仍然可见。

## 分层结构

批次规则、档案存取、页面状态分开维护：

```
src/
  domain/
    types.ts          # 色卡、批次、档案、破损区域、换批记录的类型
    batchRules.ts     # 批次规则：纯函数，输入旧档案返回新档案，不合法即抛错
  storage/
    seed.ts           # 初始档案（余量 = 到货量 - 已登记用量，保持一致）
    archiveStore.ts   # 档案存取：localStorage 读写，换掉本文件即可接后端
  state/
    useArchiveState.ts # 页面状态层：把规则包成 UI 动作，变更后持久化，展示规则错误
  components/          # 展示组件：指标、产地筛选列表、档案详情、色卡批次、换批记录
```
